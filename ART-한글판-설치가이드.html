Advanced REACH Tool 1.5

ART 한글판 설치 가이드

ART 사이트는 영어로만 나옵니다. 크롬에 작은 프로그램 하나를 얹으면 화면 글자가 한국어로 바뀝니다. 아래 화면 그대로 따라 하시면 됩니다.

전체 5분 · 크롬 필요

설치 5단계

1

크롬 웹스토어에서 Tampermonkey 설치

크롬 웹스토어에서 Tampermonkey를 검색합니다. 오른쪽 위 파란 Chrome에 추가 버튼을 누르고, 뜨는 확인창에서 확장 프로그램 추가를 누릅니다.

2

개발자 모드 켜기

주소창에 chrome://extensions 를 입력해 확장 프로그램 목록으로 갑니다. 오른쪽 위의 개발자 모드 스위치를 눌러 켭니다.

이게 꺼져 있으면 4단계를 해도 소용없습니다

개발자 모드가 꺼져 있으면 4단계의 사용자 스크립트 허용이 켜진 것처럼 파랗게 보이는데도 실제로는 동작하지 않습니다. 경고도 없습니다. 실제로 이 크롬(v151)에서 껐다 켜며 확인한 사항입니다.

3

Tampermonkey 세부정보 열기

2단계와 같은 화면입니다. 아래로 내려 Tampermonkey 카드를 찾은 뒤 세부정보를 누릅니다.

4

"사용자 스크립트 허용" 켜기

세부정보 화면을 아래로 조금 내리면 사용자 스크립트 허용이 있습니다. 오른쪽 스위치를 눌러 파란색으로 켭니다.

2단계와 4단계, 둘 다 켜져 있어야 합니다

요즘 크롬은 확장마다 이 스위치를 따로 두고 기본값이 꺼짐입니다. 이걸 안 켜면 Tampermonkey도 설치되고, 스크립트도 설치되고, 토글도 초록색인데 화면은 그대로 영어입니다. 오류 메시지조차 안 뜹니다.

개발자 모드(2단계)도 마찬가지입니다. 그게 꺼져 있으면 이 스위치가 파랗게 켜져 있어도 동작하지 않습니다. 실제로 크롬 v151 에서 개발자 모드만 껐다 켜며 확인했습니다 — 껐을 때 영어, 켰을 때 한국어였습니다.

5

한글화 스크립트 설치

스크립트 파일 전체가 아래에 들어 있습니다. 따로 내려받을 것 없이 여기서 복사해서 붙여넣으면 됩니다.

art-korean.user.js
v1.6.3 · 2,493줄 · 363 KB
// ==UserScript==
// @name         ART 한국어 (Advanced REACH Tool)
// @namespace    art-ko
// @version      1.4.1
// @description  advancedreachtool.com 화면을 한국어로 표시합니다. 표시 계층만 바꾸며 서버로 전송되는 폼 데이터는 한 바이트도 달라지지 않습니다. Alt+K 한/영 토글, Alt+C 수집 모드, Alt+E 미번역 내보내기.
// @author       -
// @match        *://*.advancedreachtool.com/*
// @match        *://advancedreachtool.com/*
// @run-at       document-idle
// @grant        none
// ==/UserScript==

위는 파일 앞부분 11줄입니다. 전체 복사를 누르면 2,300줄 전부가 클립보드로 복사됩니다.

복사했으면 Tampermonkey에 붙여넣습니다.

  1. 주소창 옆 Tampermonkey 아이콘을 누르고 대시보드를 엽니다.
  2. 왼쪽 위의 ＋ 버튼을 눌러 새 스크립트를 만듭니다.
  1. 편집기에 들어 있는 기본 내용을 Ctrl+A로 전부 선택해 지웁니다.
  2. Ctrl+V로 붙여넣고 Ctrl+S로 저장합니다.

저장됐는지 확인

설치된 유저 스크립트 탭에 아래처럼 나타나야 합니다.

목록에 안 나타난다면

저장이 안 된 것입니다. 편집기로 돌아가 붙여넣기가 제대로 됐는지 (맨 윗줄이 // ==UserScript== 인지) 확인하고 Ctrl+S를 다시 누르십시오. 편집기 위쪽 파일 → 저장을 눌러도 됩니다.

제대로 됐는지 확인하기

advancedreachtool.com 에 들어가 보십시오. 아래 오른쪽처럼 한국어로 보이면 성공입니다.

같은 페이지입니다. 메뉴가 내 시나리오 · 과학적 배경 · 지원 · 교육 · 컨소시엄으로 바뀌어 있으면 잘 된 것입니다.

안심하셔도 되는 부분

이 스크립트는 보이는 글자만 바꿉니다. ART 서버로 전송되는 값은 한 글자도 바뀌지 않습니다. 드롭다운에서 "미세 분진"을 골라도 서버에는 원래 영어 코드값이 그대로 갑니다. 실제 통신 내용을 뜯어서 확인한 사항입니다.

단축키

  • Alt + K한국어 ↔ 영어 전환. 화면이 이상해지면 이걸 눌러 영어로 되돌리십시오.
  • Alt + C번역 안 된 글자를 모으는 수집 모드를 켭니다.
  • Alt + E모은 글자를 클립보드로 내보냅니다.

안 될 때

설치는 다 했는데 화면이 그대로 영어입니다

거의 항상 스위치 문제입니다. 두 개 다 확인하십시오 — 2단계의 개발자 모드, 4단계의 사용자 스크립트 허용. 둘 중 하나만 꺼져 있어도 안 됩니다.

ART 페이지에서 Tampermonkey 아이콘을 눌렀을 때 맨 위에 파란 안내줄로 "사용자 스크립트 허용 확장 설정을 활성화하세요"가 뜨면 아직 꺼진 것입니다. 그 줄을 클릭하면 설정 화면으로 바로 갑니다.

글자가 깨지거나 반만 번역됩니다

크롬 자동 번역을 끄십시오. 주소창 오른쪽의 번역 아이콘을 눌러 "번역 안 함"을 선택합니다. 자동 번역과 이 스크립트를 같이 켜면 서로 충돌합니다.

그래도 이상하면 Alt + K로 영어로 되돌리고 알려 주십시오.

Tampermonkey 아이콘이 주소창 옆에 안 보입니다

주소창 오른쪽의 퍼즐 조각 아이콘을 누르면 설치된 확장 목록이 나옵니다. Tampermonkey 옆의 핀 모양을 누르면 주소창 옆에 고정됩니다. (3단계 세부정보 화면의 툴바에 고정 스위치를 켜도 됩니다.)

5단계에서 저장(Ctrl+S)이 안 먹습니다

순서대로 확인하십시오.

  1. 붙여넣기 전에 기본 내용을 전부 지웠습니까? 편집기 맨 윗줄이 // ==UserScript== 로 시작해야 합니다.
  2. 편집기 위쪽 파일 → 저장을 눌러 보십시오. Ctrl+S가 브라우저의 "페이지 저장"으로 새어 나가는 경우가 있습니다.
  3. 붙여넣은 양이 맞습니까? 편집기 왼쪽 줄 번호가 2,000줄 이상이어야 합니다. 몇 줄뿐이면 복사가 덜 된 것입니다.

그래도 안 되면 전체 복사를 다시 누르고 편집기를 새로 열어 처음부터 해보십시오.

중요한 평가 중인데 켜도 되나요?

진행 중인 실제 평가에 바로 얹지는 마십시오. 먼저 버려도 되는 연습용 시나리오를 하나 만들어 한 바퀴 돌려 보고, 문제가 없으면 쓰십시오. 전송 데이터가 바뀌지 않는 것은 확인했지만, 습관을 그렇게 들이는 편이 안전합니다.
